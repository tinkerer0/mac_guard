# 검증 기록

README에서 옮긴 날짜별 확인·측정 기록이다. 기준 기기는 MacBook Air(macOS 26.6), iPhone 13 mini, Apple Watch Series 7.

## 감지와 잠금 (2026-10-22)

- 실제 입력은 잡고 AI 화면 조작 같은 합성 입력은 무시했다(시험 모드 기록).
- 설치한 앱(로그인 항목)에서 실제 터치 → `SACLockScreenImmediate` 잠금 → 1초 안에 잠김 확인 → Touch ID로 풀자 경계가 자동으로 꺼졌다.
  시험 앞뒤 전원·잠자기·잠금 설정 35줄이 같았고(다른 프로그램의 잠자기 방지 목록 표시만 달라짐), 그 시간대 시스템 잠자기 기록은 0건.
- 다시 빌드·설치해도 입력 모니터링 허용이 유지됐다(개발 인증서 서명).
- APNs JWT 서명을 openssl로 교차 검증했다.
- 감지 방식을 고른 근거: HIDIdleTime만 보면 합성 입력에도 0으로 돌아가 AI 작업 중 잘못 울렸고, IOHIDManager는 내장 트랙패드 움직임을 보지 못했다.

## 부하 (2026-10-22)

- 경계 꺼짐 상태 CPU 0.00%(가짜 입력 1628건을 넣어도 0.00%), 경계 중 입력이 쏟아질 때 1.9%, 메모리 약 43MB.
- 잠금 시험 포함 42초 동안 누적 CPU 0.12초.

## 외부 공개 (2026-10-22)

- Tailscale Funnel(`https://<맥>.ts.net` → 127.0.0.1:8787) 공개 경로에서 정상 토큰 200, 틀린·없는 토큰 401.
- Tailscale 프록시를 거친 느린 무토큰 연결 40개를 열어도 앱 쪽 연결은 0개, 정상 요청은 200.

## 독립 보안 검토

- 1차(2026-10-22, 외부 모델 검토 2회): 인증 우회 0건. 결함 6건(느린 연결로 자리 고갈, 잠금 실패 뒤 재시도 없음, 요청 줄 제어 문자로 기록 위조,
  토큰 파일 권한 상속, 임시 비밀 파일 ignore 누락, 폴더 링크 처리)을 재현한 뒤 고쳤다.
- 화면 보기(2026-10-23): 토큰 없이 찍기·받기 경로 0건(무인증 120가지 요청 모두 401).
  medium 2건(시간 초과 뒤 늦은 찍기가 쌓임, 찍는 사이 경계가 꺼져도 그림 반환)을 고쳤다(30e0701).
  재검토의 low 4건(찍기 직전 재확인 없음, 시간이 지난 값 수락, 1초 간격을 요청 시각으로 셈)과 연결 시간 제한 문제
  (본문이 늦게 오고 처리가 1.5초 걸리면 응답이 사라짐, 고치기 전 4번 중 1번 재현)를 고쳤다(a74ea90).
  3차 재확인: 앞의 low 4건 해결, 새 확정 결함 없음.
- 2026-10-27 검토: medium 3·low 5 중 알림 재시도, 화면 보기 일시 거절 재시도, 설정 파일 fsync, 위젯 인증 등을 고쳤다(015a50f).
  원격으로 '경계 없이 화면 보기'를 켜는 문제는 맥 메뉴에서만 켜게 바꿨고(dcf490a), 경계를 켠 직후 유예가 없는 점은 설계대로 유지했다.

## 화면 보기 (2026-10-23, 2026-10-27)

- 설정 꺼짐 403 `disabled`, 경계 꺼짐 409 `disarmed`, 권한 없음 403 `permission`, 바로 다시 요청 429 `too-soon`.
- 권한을 준 뒤 경계 중 전체 1500×971·확대 800×518 JPEG를 받았고, 확대 그림이 전체 그림의 왼쪽 위 1/3과 맞았다
  (평균 차이 4.3, 왼쪽 아래 1/3과는 17.5).
- 찍기: 전체 1500px 한 장 0.12초·359KB. 워치 크기 450px를 공개 주소로 받기 1.35초·45KB.
- 맥→공개 주소→맥(연결 재사용): 800px 117KB 한 장 1.3~2.6초, 600px 71KB 1.5~5.2초.
  시뮬레이터 아이폰 앱 720px로 287초 동안 133장(평균 0.46장/초), 429 `too-soon` 6번은 앱이 조용히 다시 불렀다.

## 알림 방식을 고른 근거 (2026-10-27)

워치 앱에 직접 보내면 같은 알림 ID일 때 iOS가 한 기기에만 보여 줘 아이폰 사용 중엔 워치가 울리지 않았고(실기),
다른 ID면 두 번 울렸다. 그래서 아이폰에만 보내고 워치는 iOS가 넘겨주게 했다.

## 확인하지 못한 것

- 잠긴 화면에서의 입력 감지(유휴 시간 보조): 시험 때 바로 풀어 확인하지 못했다.
- Funnel 공개 경로가 끊길 때가 있다. 10-22 밤에는 맥·아이폰 모두 TLS 단계에서 끊겼고(중계 노드 연결 0, 테일넷 경로는 정상),
  10-23에는 정상이었다. 원인은 확정하지 못했다.
- 화면 보기를 워치·아이폰에서 오래 쓸 때, 잠김·화면 꺼짐 때의 거절을 실기로 확인하지 못했다.
  macOS가 화면 기록 허용을 주기적으로 다시 물을 수 있다(2024년 Sequoia 보도 기준 월 1회, macOS 26에서는 미확인).
- 워치가 아이폰 사본을 기다리느라 늦게 울리는지(포럼 보고 약 13초, Apple 문서 아님).
